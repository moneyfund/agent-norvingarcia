# 🏡 PropNica — Marketplace de Propiedades en Nicaragua

Sitio web para publicar y encontrar propiedades (venta y alquiler) en Nicaragua, con mapa interactivo.

## ¿Cómo usarlo?

1. Abre `index.html` en tu navegador
2. Verás el mapa con propiedades de ejemplo
3. Presiona **"+ Publicar propiedad"** para agregar una nueva
4. Selecciona la ubicación en el mini-mapa, llena los datos y publica

## Archivos del proyecto

- `index.html` — Estructura de la página
- `style.css` — Estilos y diseño
- `app.js` — Lógica del mapa y publicaciones
- `README.md` — Este archivo

## Tecnologías usadas

- HTML, CSS, JavaScript puro
- [Leaflet.js](https://leafletjs.com/) — mapas interactivos
- [OpenStreetMap](https://openstreetmap.org/) — tiles del mapa
- Google Fonts (Syne + Inter)

## Publicar en internet con GitHub Pages

1. Crea una cuenta en [github.com](https://github.com)
2. Crea un repositorio nuevo llamado `propiedades-nicaragua`
3. Sube estos 3 archivos (index.html, style.css, app.js)
4. Ve a Settings → Pages → Branch: main → Save
5. Tu sitio estará en: `https://tunombre.github.io/propiedades-nicaragua`
